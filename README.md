# SURL (Sanitize URL)
SURL (Sanitize URL) is a bot that scans messages on the chat application Discord for URLs that can be cleansed of excess parameters. It will then delete the senders message and repeat it with a cleansed URL, utilizing webhooks to maintain the identity of the sender.

Made using [discord.js](https://discordjs.guide/). Follow the [preparation steps](https://discordjs.guide/preparations/) to host the bot.
